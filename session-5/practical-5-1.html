Iteration and importing structured data

This practical uses purrr to do the same thing to every element of a vector or list. purrr is part of the tidyverse, so library(tidyverse) loads it. There are two parts:

  • Part 1: first steps with map().
  • Part 2: using iteration to import a folder of files.
library(tidyverse)

Part 1: First steps with map()

  1. Write a function that calculates the square of a number. Create a vector x containing the numbers 1 to 10, and use map() to apply your function to each number. Then do the same with a temporary function, \(x) ....
NoteSolution 
sq <- function(x) {
  x^2
}
x <- 1:10

map(x, sq)

map(x, \(x) x^2)
  1. Change your answer so that the result is a numeric vector rather than a list.
NoteSolution 
map_dbl(x, \(x) x^2)
 [1]   1   4   9  16  25  36  49  64  81 100

In practice, you’d just write x^2, because ^ is vectorised. map() is for functions that aren’t vectorised, or for working with lists.

  1. Create a vector of names (e.g. c("Alice", "Bob", "Charlie")) and use map_chr() to turn it into greetings such as “Hello, Alice!”.
NoteSolution 
people <- c("Alice", "Bob", "Charlie")
map_chr(people, \(x) paste0("Hello, ", x, "!"))
[1] "Hello, Alice!"   "Hello, Bob!"     "Hello, Charlie!"
  1. Here is a list of numeric vectors. Calculate the mean of each vector with map_dbl().
numbers <- list(c(1, 2, 3), c(4, 5, 6), c(7, 8, 9))
NoteSolution 
map_dbl(numbers, mean)
[1] 2 5 8

Part 2: Importing a folder of files

Data often arrives as many files with the same structure: one per hospital, per region or per year. Information is sometimes stored in the file name rather than in the data.

  1. Run this code to create a folder called penguins containing one CSV file for each combination of species and island. The species and island are removed from the data, so they are only in the file names (e.g. Adelie_Biscoe.csv).
library(fs)

dir_create("penguins")

penguins |>
  group_split(species, island) |>
  walk(\(d) {
    file_name <- paste0(d$species[1], "_", d$island[1], ".csv")
    d |>
      select(-species, -island) |>
      write_csv(path("penguins", file_name))
  })
TipWhat does this code do?

group_split() splits penguins into a list of five data frames, one for each species and island. walk() then saves each one as a CSV file. walk() is like map(), but for steps that do something (like saving a file) rather than return a result.

  1. List the files in the folder with dir_ls("penguins"). How many are there?
NoteSolution 
files <- dir_ls("penguins")
files
penguins/Adelie_Biscoe.csv    penguins/Adelie_Dream.csv     
penguins/Adelie_Torgersen.csv penguins/Chinstrap_Dream.csv  
penguins/Gentoo_Biscoe.csv

There are five files.

  1. Using a for loop, import each file with read_csv() and store the results in a list. (See the Session 1 homework for loops.)
TipHint

Create an empty list first with penguin_list <- list(). Inside the loop, store each data frame with penguin_list[[i]] <- read_csv(files[i]).

NoteSolution 
penguin_list <- list()
for (i in seq_along(files)) {
  penguin_list[[i]] <- read_csv(files[i])
}
length(penguin_list)
[1] 5
  1. Now import the files with map() instead. Then use map_int() and nrow() to count the rows in each data frame.
NoteSolution 
penguin_list <- map(files, read_csv)

map_int(penguin_list, nrow)
   penguins/Adelie_Biscoe.csv     penguins/Adelie_Dream.csv 
                           44                            56 
penguins/Adelie_Torgersen.csv  penguins/Chinstrap_Dream.csv 
                           52                            68 
   penguins/Gentoo_Biscoe.csv

map() keeps the file names as the names of the list, which the loop didn’t. That’s useful in the next question.

  1. Combine the list into a single data frame with list_rbind(). Use the names_to argument to keep the file name in a column called file.
NoteSolution 
all_penguins <- penguin_list |>
  list_rbind(names_to = "file")

all_penguins |>
  select(file, body_mass)

  1. (If you have time.) Extract the species and island from the file column, as two new columns.
TipHint

Use path_file() to remove the folder from each path and path_ext_remove() to remove the .csv, then split the result with separate_wider_delim() and delim = "_".

NoteSolution 
all_penguins <- all_penguins |>
  mutate(file = path_ext_remove(path_file(file))) |>
  separate_wider_delim(file, delim = "_", names = c("species", "island"))

all_penguins |>
  count(species, island)
