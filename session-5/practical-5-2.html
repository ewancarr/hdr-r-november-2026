across() and column-wise programming

In this practical, you’ll use across() to do the same thing to many columns at once, then c_across() to calculate across a row. We use the penguins data and the HES admissions data.

library(tidyverse)

Many columns at once

  1. Using penguins, calculate the mean of bill_len, bill_dep, flipper_len and body_mass with across() inside summarise(). Remember that some values are missing.
TipHint

Use a temporary function to pass na.rm = TRUE to mean(): \(x) mean(x, na.rm = TRUE).

NoteSolution 
penguins |>
  summarise(
    across(c(bill_len, bill_dep, flipper_len, body_mass),
           \(x) mean(x, na.rm = TRUE))
  )
  bill_len bill_dep flipper_len body_mass
1 43.92193 17.15117    200.9152  4201.754
  1. Repeat question 1, but select the columns with where(is.numeric), and calculate the medians for each species. Which column’s median isn’t useful?
NoteSolution 
penguins |>
  group_by(species) |>
  summarise(across(where(is.numeric), \(x) median(x, na.rm = TRUE)))
# A tibble: 3 × 6
  species   bill_len bill_dep flipper_len body_mass  year
  <fct>        <dbl>    <dbl>       <dbl>     <dbl> <dbl>
1 Adelie        38.8     18.4         190      3700  2008
2 Chinstrap     49.6     18.4         196      3700  2008
3 Gentoo        47.3     15           216      5000  2008

year is numeric, so it’s included, but its median isn’t very useful. You could drop it first with select(-year).

  1. Calculate both the mean and the standard deviation of the four measurement columns, for each species.
TipHint

Give across() a named list of functions, e.g. list(mean = ..., sd = ...).

NoteSolution 
penguins |>
  group_by(species) |>
  summarise(
    across(
      c(bill_len, bill_dep, flipper_len, body_mass),
      list(
        mean = \(x) mean(x, na.rm = TRUE),
        sd = \(x) sd(x, na.rm = TRUE)
      )
    )
  )

The new columns are named {column}_{function}, e.g. bill_len_mean.

  1. In mutate(), across() changes columns in place. Round every numeric column of penguins to the nearest whole number. Then convert every factor column to a character column.
NoteSolution 
penguins |>
  mutate(
    across(where(is.numeric), round),
    across(where(is.factor), as.character)

Load the HES admissions data from your course project (see the Session 3 practical if you need to set it up):

library(here)
admissions <- read_csv(here("data", "raw", "hes_admissions.csv"))
  1. Using the HES admissions data, convert the four text columns that describe the spell (admission_source, discharge_destination, provider_code and main_specialty) to factors in one step. Then count the levels of each with map_int() and nlevels(), or with summarise() and across().
NoteSolution 
admissions_f <- admissions |>
  mutate(
    across(c(admission_source, discharge_destination,
             provider_code, main_specialty),
           as.factor)
  )

admissions_f |>
  summarise(across(where(is.factor), nlevels))
# A tibble: 1 × 4
  admission_source discharge_destination provider_code main_specialty
             <int>                 <int>         <int>          <int>
1                3                     6             7              2

Either works:

map_int(select(admissions_f, where(is.factor)), nlevels)
     admission_source discharge_destination         provider_code 
                    3                     6                     7 
       main_specialty 
                    2

Across a row

  1. Here are some questionnaire scores. Calculate each participant’s total score with rowwise() and c_across(), using starts_with() to choose the item columns.
scores <- tibble(
  participant = c("A", "B", "C", "D"),
  item_1 = c(2, 2, 2, 1),
  item_2 = c(2, 1, 1, 1),
  item_3 = c(2, 0, 3, 1),
  item_4 = c(1, 0, 1, 2)
)
NoteSolution 
scores |>
  rowwise() |>
  mutate(total = sum(c_across(starts_with("item_")))) |>
  ungroup()
# A tibble: 4 × 6
  participant item_1 item_2 item_3 item_4 total
  <chr>        <dbl>  <dbl>  <dbl>  <dbl> <dbl>
1 A                2      2      2      1     7
2 B                2      1      0      0     3
3 C                2      1      3      1     7
4 D                1      1      1      2     5

ungroup() removes the row-wise grouping, so later steps work on the whole data frame again.

NoteGoing further…
  • For a simple sum, rowSums(pick(starts_with("item_"))) gives the same answer without rowwise(), and is much faster on large data.
  • In Session 2’s homework, you used .data[[col]] to refer to a column whose name is stored in an object. Write a function mean_of(data, col) that uses summarise() and .data[[col]] to return the mean of the column named in col, e.g. mean_of(penguins, "body_mass").
