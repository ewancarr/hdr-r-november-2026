Plotting with ggplot2

This practical uses ggplot2 to plot the penguins data (which you may have met in the Session 1 homework), then the HES data from Sessions 2 and 3. It has three parts:

  • Part 1: scatterplots, colours and facets.
  • Part 2: distributions, bar charts and factors.
  • Part 3: plotting the HES data.

Aim to finish Parts 1 and 2 in the session. Part 3 is for those who finish early, or for afterwards.

Part 1: Scatterplots, colours and facets

TipCan’t find the penguins dataset?

The penguins dataset was added to R in version 4.5.0. With an earlier version of R, install the palmerpenguins package and run library(palmerpenguins). Some column names are different in that version: body_mass_g rather than body_mass, and flipper_length_mm rather than flipper_len.

  1. Create a scatterplot of body mass (body_mass, y-axis) against flipper length (flipper_len, x-axis).
NoteSolution 
penguins |>
  ggplot() +
  aes(x = flipper_len, y = body_mass) +
  geom_point()
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).

R warns that it removed 2 rows containing missing values: two penguins have no measurements.

  1. Colour the points by species.
NoteSolution 
penguins |>
  ggplot() +
  aes(x = flipper_len, y = body_mass, colour = species) +
  geom_point()
  1. Add a line of best fit with geom_smooth(method = "lm"). How many lines do you get? Now move colour = species from aes() into geom_point(aes(...)). What changes, and why?
NoteSolution 
penguins |>
  ggplot() +
  aes(x = flipper_len, y = body_mass, colour = species) +
  geom_point() +
  geom_smooth(method = "lm")
penguins |>
  ggplot() +
  aes(x = flipper_len, y = body_mass) +
  geom_point(aes(colour = species)) +
  geom_smooth(method = "lm")

In the first plot, colour = species applies to every layer, so geom_smooth() fits one line per species. In the second, only the points are coloured, so geom_smooth() fits a single line to all the penguins.

  1. Split the plot from question 3 into one panel per island with facet_wrap(). Which species live on which islands?
NoteSolution 
penguins |>
  ggplot() +
  aes(x = flipper_len, y = body_mass, colour = species) +
  geom_point() +
  facet_wrap(~ island)

Adelie penguins live on all three islands; Gentoo penguins only on Biscoe; Chinstrap penguins only on Dream.

Part 2: Distributions, bar charts and factors

  1. Plot the distribution of body mass, first as a histogram (geom_histogram()) and then as a box plot for each species (geom_boxplot()).
TipHint

A histogram needs only an x aesthetic. For a box plot, put species on one axis and body_mass on the other.

NoteSolution 
penguins |>
  ggplot() +
  aes(x = body_mass) +
  geom_histogram()
penguins |>
  ggplot() +
  aes(x = species, y = body_mass) +
  geom_boxplot()

Try geom_histogram(binwidth = 100) to change the width of the bars.

  1. Draw a bar chart of the number of penguins of each species with geom_bar(). Then use fct_infreq() to order the bars from most to least common.
TipHint

geom_bar() counts the rows for you, so it needs only an x aesthetic. Wrap the column in fct_infreq() inside aes(), or create a new column with mutate() first.

NoteSolution 
penguins |>
  ggplot() +
  aes(x = species) +
  geom_bar()
penguins |>
  ggplot() +
  aes(x = fct_infreq(species)) +
  geom_bar()

species is a factor. The bars follow the order of its levels, which is alphabetical unless you change it. fct_infreq() reorders the levels by frequency.

  1. Plot the number of male and female penguins of each species, with species on the x-axis and the bars filled by sex. Remove the penguins with missing sex, and use fct_recode() to label the sexes “Female” and “Male”.
NoteSolution 
penguins |>
  filter(!is.na(sex)) |>
  mutate(sex = fct_recode(sex, "Female" = "female", "Male" = "male")) |>
  ggplot() +
  aes(x = species, fill = sex) +
  geom_bar()

Try geom_bar(position = "dodge") to put the bars side by side.

  1. Finish your plot from question 8: add a title and axis labels with labs(), and try a different theme, e.g. theme_minimal(). Then save it as a PNG file with ggsave().
NoteSolution 
penguin_plot <- penguins |>
  filter(!is.na(sex)) |>
  mutate(sex = fct_recode(sex, "Female" = "female", "Male" = "male")) |>
  ggplot() +
  aes(x = species, fill = sex) +
  geom_bar(position = "dodge") +
  labs(
    title = "Penguins by species and sex",
    x = "Species",
    y = "Number of penguins",
    fill = "Sex"
  ) +
  theme_minimal()

penguin_plot
ggsave("penguins-by-sex.png", penguin_plot, width = 6, height = 4)

ggsave() saves the file in your working directory. In a project, you’d save it in an outputs folder: ggsave(here("outputs", "penguins-by-sex.png"), ...).

Part 3: Plotting the HES data

TipStarting here?

If you don’t already have the HES data loaded, run this code first (see the Session 3 practical for how to set up the project):

library(tidyverse)
library(here)

admissions <- read_csv(here("data", "raw", "hes_admissions.csv"))
  1. Compare the length of stay (los_days) across hospitals (provider_code) with a box plot. Which hospital has the longest stays?
NoteSolution 
admissions |>
  ggplot() +
  aes(x = provider_code, y = los_days) +
  geom_boxplot() +
  labs(x = "Hospital", y = "Length of stay (days)")

R17 has the highest median length of stay (13.3 days); R11 the lowest (10.7 days).

  1. Draw a bar chart of discharge_destination. What do you notice? Clean the column as in the recoding practical (treat “UNK” and “Unknown” as missing), then order the bars by frequency.
NoteSolution 
admissions |>
  ggplot() +
  aes(x = discharge_destination) +
  geom_bar()

“UNK”, “Unknown” and NA all mean the same thing: the destination wasn’t recorded.

admissions |>
  mutate(
    discharge_destination = case_when(
      discharge_destination %in% c("UNK", "Unknown") ~ NA,
      .default = discharge_destination
    )
  ) |>
  ggplot() +
  aes(x = fct_infreq(discharge_destination)) +
  geom_bar() +
  labs(x = "Discharge destination", y = "Number of spells")

fct_infreq() puts NA last, whatever its count.

  • Use fct_lump_n() to keep the two most common discharge destinations and group the rest as “Other”.
