Air pollution and health

Do London boroughs with more air pollution have more emergency hospital admissions?

Air pollution is a known risk factor for respiratory and cardiovascular diseases. High pollution levels can exacerbate conditions like asthma, COPD, and heart disease, leading to increased hospital admissions and mortality. Open datasets, such as those on the London Datastore and the Fingertips public health website, let us compare pollution levels with health outcomes across areas.

In this project you’ll look at the relationship between air pollution and emergency hospital admissions across London boroughs, using open data. You’ll download, clean, and combine the two datasets, then look at how they’re related.

The project practises skills from Sessions 1 to 4, including data import, manipulation, creating and modifying columns (e.g., mutate), and merging (e.g., inner_join). Once the data is cleaned and combined, you’ll create plots to illustrate the relationships in the data.

NoteHow the mini project works
  • Session 4: we’ll spend the last 20 minutes getting started: setting up the project and importing the data (sections 1.1 and 1.2). Don’t worry if you don’t finish the import in the session.
  • Before Session 5: carry on in your own time, as far as you can.
  • Session 5: we’ll start with a walkthrough of one possible solution, and time for questions.

Extracting data via an API is optional, for those who want more of a challenge.

1 Air pollution and hospital admissions

In this exercise we’ll look at how air pollution is related to hospital admissions across London boroughs. We’ll use information from the London Datastore, in particular:

  1. London Atmospheric Emissions Inventory (LAEI) 2016 The file we’ll use has two measures for each London borough: the population-weighted average PM2.5 concentration in 2016, and the number of people living where NO2 concentrations exceed the limit (2013 and 2016).

  2. Hospital Admission Rates Emergency hospital admission rates for all ages, with one sheet for each financial year from 2003-04 to 2014-15. They include admissions for all conditions.

Your goal is to clean, merge, and visualise this data.

1.1 Set up the project

  • Create an RStudio project for the mini project, with data/raw, data/processed, scripts and outputs folders, as in the Session 3 practical.
  • Download the following two files and save them in data/raw:
    • Population_exceeding_LAEI2016.xlsx
    • hospital-admissions-rates-borough.xls
  • Write up your work as a Quarto document (e.g. mini-project.qmd), so your code, plots and comments are in one place. See the Quarto slides and the homework for how to start one.

1.2 Import and inspect

  • Load any required packages. At a minimum, I recommend:

    library(tidyverse)
library(janitor)
library(readxl)
library(here)

    If you haven’t used janitor or here before, install them first with install.packages(c("janitor", "here")).

  • Import the two datasets into R, using here("data", "raw", ...) for the file paths. For hospital admissions, use the most recent year, 2014-15.

  • Check their structure (str, head, glimpse).

  • Identify key variables: borough names, PM2.5 levels, and the admission rate. For the rate, use the indirectly age and sex standardised rate per 100,000.

TipTips
  • Each file has several sheets. Use excel_sheets() to see their names, then choose one with the sheet argument of read_excel().
  • The PM2.5 table doesn’t start on the first row. Open the file in Excel to see where it starts, then use the skip or range argument of read_excel().
  • Look for inconsistencies in variable names and formats between datasets.

1.3 Data cleaning

  • Remove unnecessary rows (e.g., blank rows, and totals for Inner and Outer London, the English regions, and England).
  • Ensure borough names match between datasets.
  • Rename and recode variables for consistency.
TipTips
  • Use janitor::clean_names() to simplify column names.
  • You may need to fix some borough names by hand, e.g., with subsetting and assignment.

1.4 Merge

  • Use appropriate joining functions (e.g., inner_join, full_join) to combine information on PM2.5 (fine particulate matter) with information on hospital admissions.
  • Use anti_join() to find rows in one dataset with no match in the other.
  • Check how many rows you have after merging. London has 33 boroughs (including the City of London).

1.5 Explore the merged data

  • Summarise key statistics (summary(), count()) and tabulate the included boroughs.
  • Check for missing values (sum(is.na())).
  • Inspect distributions of PM2.5 levels and hospital admissions.
Tip
  • Use ggplot2::geom_histogram() to visualise distributions before plotting relationships.

1.6 Visualise the relationship

  • Create a scatter plot of PM2.5 vs. hospital admissions rate.
  • Label the boroughs, or the ones with the highest values.
  • Which boroughs stand out from the rest? Do their values look plausible?
Tip
  • Try adding a trend line with geom_smooth(method = "lm") to explore patterns.
  • To label points without the labels overlapping, try geom_text_repel() from the ggrepel package (install it with install.packages("ggrepel")).

Reflection

  • Does the data suggest a link between pollution and hospital admissions?
  • What limitations might affect this analysis?
  • What additional data could strengthen the investigation?

2 Extracting data via an API

NoteOptional

This section is an optional extra for after the course, or if you finish section 1 early.

In this part, we’ll continue to explore relationships between air pollution and population health outcomes, but this time, we’ll download the required data directly via an API. You will:

  1. Retrieve and clean public health data using the fingertipsR package.
  2. Merge datasets to examine borough-level trends.
  3. Visualise relationships between pollution and health outcomes.

This exercise is open-ended and harder than the one above.

2.1 Install and load the necessary packages

We’ll use the fingertipsR package to download data from Fingertips, the public health data service run by the Office for Health Improvement and Disparities (formerly part of Public Health England). Before we start, browse the website to get a feel for the available datasets.

You’ll need to install the fingertipsR package. It isn’t on CRAN, so install it from GitHub with the pak package, which also handles package dependencies for us:

install.packages("pak")
pak::pak("ropensci/fingertipsR")

library(tidyverse)
library(janitor)
library(fingertipsR)

2.2 Identify relevant indicators

The Fingertips API provides information on a wide range of public health indicators for England.

As a first step, use the indicators_unique function to extract a list of the available measures. For example:

ind <- indicators_unique()

ind |> filter(str_detect(IndicatorName, "pollution"))
ind |> filter(str_detect(IndicatorName, "Mortality rate"))

From the lists above, let’s choose:

  • 93963: Mortality rate from respiratory disease, all ages
  • 93867: Air pollution: fine particulate matter

2.3 Extract information for these two indicators

  • Use the fingertips_data function to extract information for each indicator (see the help file if you’re unsure).
  • Use AreaTypeID = 501 to select information for local authority districts.
  • This gives you every district in England. To keep only the London boroughs, filter on area codes starting with E09.

2.4 Clean and merge the two datasets

  • The mortality data has separate rows for males, females, and persons. Keep sex == "Persons".
  • Mortality is reported both for single years (e.g., 2019) and for 3-year periods (e.g., 2017 - 19). Use the timeperiod column to keep the single years, and create a numeric year column in both datasets.
  • PM2.5 is only available from 2018, so that’s the earliest year you can compare.
  • Merge on area (e.g., area_code) and year. Before merging, check that each dataset has one row per area and year (e.g., with count(area_code, year)). If not, the join will repeat rows.

2.5 Plot the merged dataset

You might consider:

  • A scatter plot of air pollution and mortality rate for a single year.
  • A line plot of air pollution and mortality over time for a few boroughs. (This may need further reshaping.)

3 Going further

If you’ve got this far and run out of things to do, here are two ideas.

3.1 Admissions over time

The hospital admissions file has one sheet per financial year, from 2003-04 to 2014-15.

  • Import every sheet and combine them into one dataset, with a column for the year. You’ll need some form of iteration, e.g., looping over the sheet names from excel_sheets().
  • The 2009-10 and 2010-11 sheets contain no data, so check what you get for those years.
  • Create a time series plot of admission rates for each borough. Do any boroughs change suddenly? Is that likely to be a real change in health, or a change in how admissions were recorded?

3.2 Projected health impacts

This study estimates the long-term health impacts of air pollution in each London borough from 2016 to 2050.

  • The results come as separate Excel (.xlsm) files for each borough and pollutant, so you’ll need to download, import, and combine many files that share the same layout. Again, you’ll need iteration.
  • The figures are projections from a model. What assumptions does the model make?
