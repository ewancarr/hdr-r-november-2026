Reshaping and summarising

In this practical we’ll use the spell-level table dat from the joining practical to group and summarise the data, compare outcomes between groups, and reshape results between long and wide formats.

All data in this practical is simulated for teaching purposes.

TipStarting here?

If you haven’t done the recoding and joining practicals, run this code first (see Recoding columns for how to set up the project):

library(tidyverse)
library(here)

patients <- read_csv(here("data", "raw", "hes_patients.csv"))
admissions <- read_csv(here("data", "raw", "hes_admissions.csv"))
episodes <- read_csv(here("data", "raw", "hes_episodes.csv"))
outcomes <- read_csv(here("data", "raw", "hes_outcomes.csv"))

admissions <- admissions |>
  mutate(
    discharge_destination = case_when(
      discharge_destination %in% c("UNK", "Unknown") ~ NA,
      .default = discharge_destination
    )
  )

spell_tbl <- admissions |>
  inner_join(outcomes, by = "spell_id") |>
  inner_join(patients, by = "patient_id")

episode_counts <- episodes |>
  count(spell_id, name = "n_episodes")

dat <- spell_tbl |>
  left_join(episode_counts, by = "spell_id")

Summarise episodes

  1. (Optional) Later questions don’t use episode_summary, so skip this if you’re short of time.

    In the joining practical, we used count() to count the episodes in each spell. To calculate other summaries for each spell, we need group_by() and summarise(). First, run this code, which adds the length of each episode in days:

    # Date arithmetic is covered in Session 4
episodes <- episodes |>
  mutate(episode_days = as.numeric(episode_end - episode_start))

    Then create episode_summary from episodes, with one row per spell and these columns:

    • n_episodes: the number of episodes in the spell
    • total_episode_days: the total number of days covered by the episodes in the spell
    • n_consultant_specialties: the number of different consultant specialties in the spell

    How many spells involved three different specialties? If you like, join episode_summary to dat too (drop its n_episodes column first, since dat already has one).

TipHint

Inside summarise(), use n() to count the rows in each group, and n_distinct() to count the different values of a column.

NoteSolution 
episode_summary <- episodes |>
  group_by(spell_id) |>
  summarise(
    n_episodes = n(),
    total_episode_days = sum(episode_days),
    n_consultant_specialties = n_distinct(consultant_specialty)
  )

Derive analysis fields

  1. Create two new columns in dat using case_when(), and store the result by overwriting dat:

    • deprivation_group, based on imd_quintile: “More deprived” for quintiles 1 and 2, “Middle” for quintile 3, and “Less deprived” for quintiles 4 and 5.
    • surgery_delay_group, based on time_to_surgery_days: “<=2 days” if surgery was within 2 days of admission, and “>2 days” otherwise.

    Use count() to check that each new column has been created correctly.

NoteSolution 
dat <- dat |>
  mutate(
    deprivation_group = case_when(
      imd_quintile %in% c(1, 2) ~ "More deprived",
      imd_quintile == 3 ~ "Middle",
      imd_quintile %in% c(4, 5) ~ "Less deprived"
    ),
    surgery_delay_group = case_when(
      time_to_surgery_days <= 2 ~ "<=2 days",
      time_to_surgery_days > 2 ~ ">2 days"
    )
  )

dat |>
  count(imd_quintile, deprivation_group)

dat |>

1 <=2 days             1830

Counting the old and new columns together shows that each quintile has gone into the right group, with no NA values. 1,830 spells had surgery within 2 days, and 4,863 waited longer.

Make comparisons

  1. Compare outcome rates between the two surgery delay groups. For each group, calculate the number of spells and the proportion with each of these outcomes:

    • readmission_30d
    • death_30d
    • long_stay_flag
TipHint

The outcome columns are coded 0 (no) and 1 (yes), so the mean of each column is the proportion of spells with that outcome.

NoteSolution 
dat |>
  group_by(surgery_delay_group) |>
  summarise(
    n = n(),
    readmission_30d_rate = mean(readmission_30d),
    death_30d_rate = mean(death_30d),
    long_stay_rate = mean(long_stay_flag)
  )
# A tibble: 2 × 5
  surgery_delay_group     n readmission_30d_rate death_30d_rate long_stay_rate
  <chr>               <int>                <dbl>          <dbl>          <dbl>
1 <=2 days             1830               0.0874         0.0175         0.0464
2 >2 days              4863               0.115          0.0319         0.320

All three outcomes are more common when surgery is delayed by more than 2 days. For example, 3.2% of these patients died within 30 days, compared with 1.7% of those who had surgery within 2 days.

NoteSolution 
dat |>

When you group by more than one variable, summarise() removes the last grouping variable from the result and prints a message about it. .groups = "drop" removes all the grouping instead, which avoids the message.

Note that the groups are sorted alphabetically (“Less deprived”, “Middle”, “More deprived”), not in order of deprivation.

Reshape

  1. In question 3 we wrote a separate mean() for each outcome. Another approach is to reshape the data first. Reshape dat so that the three outcome columns (readmission_30d, death_30d and long_stay_flag) are stacked into two columns: outcome (the name of the outcome) and value (0 or 1). How many rows does the result have? Then use group_by() and summarise() to calculate the rate of each outcome in each surgery delay group, and check that you get the same answers as in question 3.
NoteSolution 
dat_long <- dat |>
  select(spell_id, surgery_delay_group, readmission_30d, death_30d, long_stay_flag) |>
  pivot_longer(
    c(readmission_30d, death_30d, long_stay_flag),
    names_to = "outcome",
    values_to = "value"
  )

Calculate the 30-day readmission and mortality rates for each hospital, using the same approach as question 6, so that you have one row for each combination of hospital and outcome (a “long” table with 14 rows). Then use pivot_wider() to reshape the result so that there is one row per hospital and one column for each outcome. Which hospital had the highest 30-day mortality?
TipHint

pivot_wider() is the opposite of pivot_longer(). names_from names the column whose values become the new column names, and values_from names the column that fills them:

long_table |>
  pivot_wider(names_from = name_column, values_from = value_column)
