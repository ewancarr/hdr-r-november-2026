These optional exercises bring together the two topics from Session 2: writing functions and working with data frames. You’ll write a few small functions that take a data frame and the name of a column, and return something useful about that column. We’ll use the starwars dataset and the HES admissions data from Practical 2.

Using a column name inside a function

In Session 1 we saw that you can pull out a column from a data frame using $ or [[. Inside a function, [[ is the one to use, because it accepts the column name as a character string stored in an object:

Exercises

  1. Write a function, column_mean(), that returns the mean of a column, ignoring missing values. It takes two arguments:
    • data: a data frame
    • col: the name of a column
    Test it on the height column of starwars and the los_days column of admissions.
NoteSolution 
column_mean <- function(data, col) {
  mean(data[[col]], na.rm = TRUE)
}

column_mean(starwars, "height")
[1] 174.6049
column_mean(admissions, "los_days")
[1] 11.95874
NoteGoing further…

What happens if you give column_mean() a column that doesn’t exist (e.g. "weight"), or a character column (e.g. "name")? Update your function to check that the column exists and is numeric, and to stop with an informative error message if not. (Hint: names(data) gives the column names, and is.numeric() checks whether a vector is numeric.)

Without any checks, both calls return NA with a warning, which is easy to miss. Here is one solution:

Show the solution 
column_mean <- function(data, col) {
  if (!(col %in% names(data))) {
    stop("Column '", col, "' not found in the data.")
  } else if (!is.numeric(data[[col]])) {
    stop("Column '", col, "' must be numeric.")
  }
  mean(data[[col]], na.rm = TRUE)
}
  1. Write a function, count_missing(), that returns the number of missing values in a column. How many are there in:
    • mass in starwars?
    • discharge_destination in admissions?
NoteSolution

is.na() returns TRUE for each missing value, and sum() counts the TRUE values.

count_missing <- function(data, col) {
  sum(is.na(data[[col]]))
}

count_missing(starwars, "mass")
[1] 28
count_missing(admissions, "discharge_destination")
[1] 67

There are 28 missing values in mass, and 67 in discharge_destination. A further 134 destinations are recorded as “UNK” or “Unknown”, which R doesn’t treat as missing. We’ll clean these up in Part 2 of Practical 2, at the start of Session 3.

  1. Write a function, column_summary(), that returns a one-row data frame for a numeric column, containing:
    • the mean, standard deviation, minimum and maximum, rounded to one decimal place
    • the number of missing values (use your count_missing() function from question 2)
NoteSolution 
column_summary <- function(data, col) {
  x <- data[[col]]
  data.frame(
    column = col,
    mean = round(mean(x, na.rm = TRUE), 1),
    sd = round(sd(x, na.rm = TRUE), 1),
    min = round(min(x, na.rm = TRUE), 1),
    max = round(max(x, na.rm = TRUE), 1),
    n_missing = count_missing(data, col)
  )
}

column_summary(starwars, "height")
  column  mean   sd min max n_missing
1 height 174.6 34.8  66 264         6
column_summary(admissions, "los_days")
    column mean sd min  max n_missing
1 los_days   12  3   2 22.4         0
  1. Write a function, keep_above(), that takes a data frame, a column name and a threshold, and keeps only the rows where that column is greater than the threshold. Use it to find:
    • characters in starwars with a mass over 100
    • spells in admissions longer than 14 days
TipHint

Inside filter(), you can refer to a column whose name is stored in an object using .data[[col]]. Alternatively, use [[ to make a logical vector and pass that to filter().

NoteSolution 
keep_above <- function(data, col, threshold) {
  data |>
    filter(.data[[col]] > threshold)
}

keep_above(starwars, "mass", 100)

There are 10 characters with a mass over 100, and 1,574 spells longer than 14 days (the same as question 4 of Practical 2). Note that filter() drops rows where the condition is NA, so characters with a missing mass are not kept.

Here .data stands for “the data frame being filtered”, and .data[[col]] works just like data[[col]]. There are other ways of passing column names into dplyr functions: see Programming with dplyr if you’re interested.
